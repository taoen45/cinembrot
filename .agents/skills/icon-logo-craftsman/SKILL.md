# Icon & Logo Craftsman Skill

## Standar Aset Visual & Ikonografi
1. **Vektor SVG Mandiri (Inline SVG)**:
   - Prioritaskan inline SVG bersih dengan atribut `viewBox="0 0 24 24"`, `fill="none"`, `stroke="currentColor"`.
   - Hindari dependensi CDN eksternal yang dapat memperlambat First Contentful Paint (FCP).
2. **Library Ikon Terkurasi**:
   - Manfaatkan ikon Lucide atau FontAwesome versi free/lightweight.
3. **Favicon & Web App Manifest**:
   - Sediakan format `favicon.ico`, `favicon.png` (32x32 & 192x192), dan Apple Touch Icon.
   - Kompresi lossless untuk meminimalkan ukuran file (< 5 KB).
